# Kuyen Arbell — maqueta comercial

Maqueta navegable **100% frontend**, creada a partir de los recursos del proyecto original. No es el producto final contratado.

## Recorrido

- `index.html`: bienvenida y dos caminos.
- `comunidad.html`: propuesta para revendedores, presentación de Eluney, espacios para videos y redes.
- `productos.html`: productos ilustrativos, espacios para videos, catálogo y contacto.
- `css/main.css`: estilos compartidos y responsive.
- `js/main.js`: mensajes de WhatsApp y año del footer.
- `assets/images/`: fotografías y logos del ZIP original.

## Para probar

Abrir `index.html` con Live Server de VS Code. No requiere instalación ni dependencias.

## Publicación en Vercel

Subir el contenido de esta carpeta a un repositorio GitHub y elegir **Add New → Project → Import Git Repository** en Vercel. Framework Preset: **Other**. Build Command: vacío. Output Directory: vacío (raíz del repositorio). Deploy. `index.html` es la entrada.

## Alcance de la maqueta

**Implementado:** navegación entre tres pantallas, diseño responsive, fotografías de Eluney, identidad Kuyen, enlaces a Instagram/TikTok, enlace al catálogo Arbell y mensajes diferenciados de WhatsApp.

**Ilustrativo o pendiente:** fotografías y fichas de productos definitivos, videos reales, introducción cinematográfica, animaciones avanzadas, contenido personal aprobado, analítica y optimización final. No hay backend, pagos ni carrito.

## Propuesta / presupuesto: apartados para completar

1. Objetivo: landing de marca personal y dos recorridos (compradores/revendedores).
2. Entregables: diseño responsive, contenido aprobado, productos destacados, videos seleccionados, botones WhatsApp diferenciados, enlaces a redes, dominio y despliegue según acuerdo.
3. Animaciones: introducción cinematográfica y microinteracciones, sujeto a material disponible y alcance acordado.
4. Insumos a entregar por cliente: imágenes y nombres de productos, videos/URLs, biografía aprobada, logo definitivo y accesos necesarios.
5. Exclusiones: ecommerce, pagos, carrito, backend, carga autogestionable y producción audiovisual, salvo cotización expresa.
6. Cronograma: definir una vez aprobados alcance y materiales.
7. Inversión, forma de pago, cantidad de revisiones y mantenimiento: definir en presupuesto.

**Importante:** las tarjetas y textos de demostración no afirman la existencia de productos o videos específicos.
